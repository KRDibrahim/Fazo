# FAZO

FAZO is a mobile game for autistic children, built with Unity for Android tablets and phones. It presents short learning activities in a fixed, predictable format, with no failure states, no time pressure and a calm visual and sound design.

## Overview

Each activity is made of small steps that follow the same pattern: **Show** (the child sees something new), **Check** (the child answers a simple question) and, where suitable, **Use** (the child applies it in a new setting). Content is organised into learning domains such as shapes and animals, and into three sections: Learn, Combine and Apply.

Adults manage child profiles and settings behind a guardian gate, and can view a progress overview for each child.

## Current features

- Child profiles and a "Who's playing" screen
- Section gateway with a points meter and a session wind-down meter
- Session map and activity map
- Settings for audio, assistance, language and session length
- Child details screen with a progress overview

## Status

Early development. The main screens and navigation are working. Playable learning steps, data storage and audio are in progress.

## Built with

Unity, UI Toolkit, C#
